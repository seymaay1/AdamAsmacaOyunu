# AdamAsmacaOyunu
Java Swing ile geliştirilmiş şifre korumalı Adam Asmaca oyunu
Oyun, şifre korumalı giriş sistemi, skor takibi ve log kayıt özellikleriyle donatılmıştır.
Özellikler
-  Şifre korumalı giriş sistemi
-  3 hatalı girişte program otomatik kapanır
-  11 aşamalı adam asmaca görseli
-  Harf ve kelime tahmini desteği
-  Oyun süresi sayacı
-  Skor kayıt ve listeleme sistemi
-  Giriş log kayıt sistemi
-  3 sekmeli arayüz (Oyun, Skorlar, Loglar)
-  Tüm veriler dosyaya kaydedilir

---

##  Kullanılan Teknolojiler
- Java 17
- Java Swing
- Apache NetBeans

  ## ⚙️ Kurulum
1. `C:/P2OYUN/Resimler` klasörüne 1.jpg ile 11.jpg arasındaki resimleri ekle
2. `C:/P2OYUN/TXTDosyalar` klasörüne `kelimeler.txt` dosyasını ekle
3. `sifre.txt`, `oyunlar.txt` ve `log.txt` dosyalarını boş olarak oluştur
4. Projeyi NetBeans ile aç ve çalıştır
5. İlk açılışta şifre belirleme ekranı gelir, şifreni belirle

---

##  Nasıl Oynanır
1. Şifre ekranından giriş yap
2. Oyun sekmesinde rastgele bir kelime seçilir, harfler `*` ile gösterilir
3. Harf tahmini alanına bir harf gir ve "Tahmin et" butonuna bas
4. Kelime tahmini alanına kelimenin tamamını yazabilirsin
5. 11 yanlış tahminde oyun kaybedilir
6. Tüm harfleri doğru bulursan oyun kazanılır
7. Menüden "Yeni Oyun" veya "Baştan Başla" seçebilirsin
